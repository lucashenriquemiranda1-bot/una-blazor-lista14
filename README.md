 # Guia de Execução

Siga os passos abaixo para executar o projeto via terminal:

# Acessar a pasta do projeto:
cd MeuCurriculo

# Restaurar dependências:
dotnet restore

# Executar aplicação:
dotnet run

Após executar, o navegador abrirá automaticamente com a aplicação rodando localmente.

 # Heurística – 

O sistema foi desenvolvido seguindo a heurística de “Ajuda e documentação”, garantindo que, mesmo sendo simples de usar, o usuário possa compreender facilmente seu funcionamento.

A interface apresenta informações organizadas e diretas
Os elementos visuais são autoexplicativos
O conteúdo é estruturado de forma clara, facilitando a navegação
Caso necessário, o usuário consegue entender rapidamente onde encontrar cada informação

Dessa forma, o sistema mantém simplicidade no uso, mas ainda oferece suporte implícito ao usuário.
